
# FighterPosting

NOTE: This site is no longer maintained! HUNGARIAN below

## Introduction

The [fighterposting.hu](www.fighterposting.hu) (formerly fighterposting.online) is a collector site of Digital Civic Circles (in Hungarian: Digitális Polgári Körök) and Fighter's Club  (in Hungarian: Harcosok Klubja) Facebook posts and text messages.

## Usage

On the front page, the users can track the comment raid requests. On desktop, the user can see the posts like a timeline, meanwhile on mobile, a message book is visible, where each SMS message is visible, which was sent during the 2026 election campaign.

If the user decides to navigate further on the page, they can select "Tovább a Fighterpostingra" (in English: Go to Fighterposting) button, where additional posts and comments are visible from group members.

## Bemutatás

A [fighterposting.hu](www.fighterposting.hu) (régebben fighterposting.online) egy gyüjtő oldal olyan SMS-eknek és ahhoz Facebook posztoknak, melyek a Digitális Polgári Körökhöz vagy a Harcosok Klubjához kapcsolódnak.


## Használat

A legelső oldalon a felhasználó láthatja a bejegyzés megrohamozási kéréseket (raid). Asztali nézetben megtekintheti a felhasználó a bejegyzéseket, idővonal szerűen, míg mobilnézetben a kiküldött SMS-eket csodálhatjuk meg.

Ha a felhasználó úgy dönt, hogy szétnézne az oldalon, akkor rákattinthat a "Tovább a fighterpostingra" gombra, ahol további bejegyzések és kommentek láthatóak DPK és HK csoportok tagjaitól.
